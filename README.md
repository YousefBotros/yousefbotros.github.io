# Yousef Portfolio (HTML/CSS/JS)

## Run locally
Just open `index.html` in your browser.

## Deploy on GitHub Pages (quick)
1. Create a repo (recommended name: `yousefbotros.github.io`)
2. Upload files (index.html, style.css, script.js)
3. Repo Settings → Pages → Deploy from branch → `main` + `/(root)`
4. site: https://yousefbotros.github.io
